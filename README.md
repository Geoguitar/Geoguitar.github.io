## 📌 Sobre o Projeto

Este repositório contém o código-fonte do meu portfólio web responsivo, hospedado via **GitHub Pages**. O objetivo do projeto é consolidar e expor minha experiência profissional como **Desenvolvedor Full Stack, Analista de TI e Educador**, além de destacar meus projetos em **Arquitetura Java, Spring Boot, Bancos de Dados e Containerização**.

🔗 **Acesse o portfólio online:** [geoguitar.github.io](https://geoguitar.github.io)

---

## 🛠️ Especialidades e Tecnologias

O projeto foi construído focando em **Clean Code**, alta performance e total responsividade para dispositivos móveis e desktop.

### **Front-end & Interface**
- **HTML5 & CSS3:** Semântica estruturada (W3C compliant) com estilização customizada e suporte a efeito Parallax.
- **Bootstrap 5:** Framework para layout responsivo, sistema de grid moderno e componentes integrados via CDN.
- **JavaScript (ES6+):** Scripts leves para manipulação do DOM e navegação.

### **Especialidades Técnicas Representadas**
- **Backend:** Java, Spring Framework / Spring Boot, REST APIs, PostgreSQL, MongoDB, PL/SQL.
- **Infraestrutura & DevOps:** Ambientes Linux, Containerização com Docker, gestão de servidores.
